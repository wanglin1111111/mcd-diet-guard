# 阈值口径与指标解释

## 阈值来源

脚本中 8 个画像的默认阈值，采用以下口径：

- **钠**：中国居民膳食营养素参考摄入量建议成人每日钠摄入 <2000mg
  （≈食盐 5g）。**高血压人群建议更低**，本 Skill 取 500mg/份 作为套餐级上限。
- **碳水 / 糖**：以单餐可接受范围设定（血糖管理场景碳水 ≤40g、添加糖 ≤15g）。
- **饱和脂肪**：以单餐占比上限设定（通用 ≤12g，高血压 ≤8g，减脂 ≤6g）。
- **能量**：按单餐占日均能量的比例反推（减脂/儿童 ≤500kcal，增肌 ≤900kcal）。

★ 这些是**通用参考口径**，用于给出可解释的判定，不是医学处方。
  输出时必须带上口径说明，让用户知道阈值从哪来、可以按自己情况改。

## 用户自述优先

用户说「我一天控制在 1500 大卡」「我需要每天 100g 蛋白」时，
用 `constraints` 覆盖，不要争辩通用阈值。

```json
{ "profile": "weightloss", "constraints": { "energy_kcal": 400 } }
```

## 为什么用密度

绝对值跨餐品不可比——同样热量档的两个汉堡，钠可以差一倍以上。
按每 100kcal 归一化后（MCP 实测值）：

| 餐品 | 能量 | 钠 | 钠密度 |
|---|---:|---:|---:|
| 猪柳炒双蛋堡 | 437kcal | 705mg | 161 mg/100kcal |
| 巨无霸 | 513kcal | 961mg | 187 mg/100kcal |
| 双层吉士汉堡 | 429kcal | 1017mg | 237 mg/100kcal |
| 果然多肉 | 478kcal | 1343mg | **281 mg/100kcal** |

同为400–550kcal 能量档，最低钠 258mg、最高 1343mg，**差 5.2 倍**——
单看绝对值或热量都判断不出这个跨度。

★ 判据：比较**不同大小**的两个餐品是否高钠，看钠密度；
  比较**同等热量**的选项，直接看绝对值更直观。
  两者别混用，否则会得出矛盾结论。

## 钠密度阈值 150 的由来

麦当劳主餐钠密度实测多落在 **60~210 mg/100kcal**。
- >150：同能量下明显偏高，值得提示
- ≤150：不提示（快餐普遍高钠，低频提示才有筛选力）

★ 反例：把阈值设成 2.5（看起来更"严格"）会让几乎每样都触发，等于没筛选。
  这个数字是校准过的，不要凭直觉改。

## 蛋白密度

`protein_per_100kcal ≥ 10 g/100kcal` 视为高蛋白密度。
增肌画像下，单餐蛋白 ≥25g 单独记为达标项（正向提示，不只是扣分项）。

## 痛风的类别估算

MCP **不提供嘌呤含量数据**。本 Skill 只能按标签做类别分级：

| 风险级 | 命中标签 | 判定 |
|---|---|---|
| 3 | 内脏类（organ/liver/gizzard/blood） | 🔴 高风险类别 |
| 2 | 红肉类（beef/pork/chicken/meat/bacon） | 🟡 中风险类别 |
| 1 | 海鲜 / 肉汁（seafood/shrimp/fish/sauce-gravy） | 提示留意 |
| 0 | 均未命中 | 无类别风险提示 |

★ 这是**类别估算，不是嘌呤含量实测值**。输出必须标注「估算」。
  绝不写具体嘌呤毫克数——MCP 没有这个数据，写了就是编造。
  痛风患者的实际饮食须遵医嘱。

## 免责声明的两种情况

1. **必须带**：涉及高血压、糖尿病、痛风、孕期等疾病相关画像
2. **建议带**：`general` 画像提及健康风险时

固定表述：本工具为参赛作品输出，不构成医疗、营养或其他专业建议；
营养数值来自麦当劳 MCP 实时返回，餐品成分与供应状态以官方渠道为准。
